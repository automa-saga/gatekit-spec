# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities **privately** — do not open a public issue
or discuss the problem in public before it is resolved.

Use GitHub's private vulnerability reporting: open the repository's **Security**
tab and click **"Report a vulnerability"** to file a private security advisory.
This reaches the maintainers directly and keeps the details confidential.

This repository holds the gatekit specification and its conformance fixtures
(documentation and JSON data, no executable library), so most reports here will
concern errors or ambiguities in the spec or fixtures. Include the affected
document or fixture and the impact. We will acknowledge your report, investigate,
and coordinate any correction with you.
